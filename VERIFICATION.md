## Unverified

- The shared geometry baseline is rewritten by whichever capture job's artifact is copied last; the three OSes differ by 1 px on one element, inside the 8 px tolerance.
- Windows arm64 and macOS Intel run only the real-shell suite, not the browser suite or the installers.
- Nothing is signed or notarized; the release notes say which warning each OS shows.
- The rpm bundle has no installer round trip; it ships labelled a preview.
- Clear button (trial/clear-button): no CI run; ubuntu, macOS and the arm64 and Intel runners have not seen it. The tier 3 pixel baselines predate the button and were not recaptured; they still pass locally on win32 only because the change (4590 px at zero tolerance) is under maxDiffPixelRatio 0.002 with the default 0.2 colour threshold. Refresh them through the snapshots workflow.
- Tier 1 ARIA matching is partial: an added control does not fail it, only a missing or renamed one does.
